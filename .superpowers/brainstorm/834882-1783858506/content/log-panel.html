Promtail 解析 pipeline

# 当前日志格式 (Logstash):
{"@timestamp":"2026-07-12T10:30:00Z","level":"INFO","traceId":"abc123","service":"order-service","message":"..."}
# Promtail 提取 labels:
- service = "order-service"
- level = "INFO" / "ERROR" / "WARN"
- # 保留 JSON 全文供 Loki 全文检索
