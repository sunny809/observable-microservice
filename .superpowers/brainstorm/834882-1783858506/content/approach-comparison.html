方案 A：完整本地可观测性栈 推荐

架构概览

→
📈 Grafana
Unified UI
Dashboards + Explore

技术栈：Grafana + Prometheus + Loki + Promtail + Jaeger — 全部 docker-compose 一键启动

包含：预置的 Grafana dashboards (JSON 配置) + Prometheus 抓取规则 + Loki 日志采集 + 告警规则

优势

  • 一键启动完整栈，学习者马上看到全貌
  • 预置的 JSON dashboard 可直接移植到生产环境
  • Loki 日志聚合实现日志搜索 + 从日志跳转到指标

代价

  • 需要额外资源：docker-compose 启动多个容器
  • Loki 配置有一定复杂度

方案 B：Grafana Cloud + 本地采集

技术栈：Grafana Cloud (SaaS) + Prometheus Agent + Loki Agent 本地采集

优势

  • 无需自运维 Grafana/Prometheus/Loki
  • Grafana Cloud 免费层够用
  • 更接近企业实际部署方式

代价

  • 需要注册外部账号，学习者体验门槛高
  • 不可离线使用
  • 无法展示完整架构配置
